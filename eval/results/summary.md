This rate is a property of this corpus, not of warden. It says every attack
someone thought to write down was stopped; it cannot say anything about the
attacks nobody wrote. The corpus was written by the same author as the code,
which is the strongest reason to read it with suspicion, and the expected
non-blocks below are where the honest limits of the design are recorded.

That is not a hypothetical caveat. The T1 framing cases were added after a
real client found the class they cover — a bypass that sat under a 100%
block rate because no case in the corpus could express the message shape.

## Attribution of the blocks

A block is not the whole result. SPEC contribution 3 is the decision trace,
so the case's `want_ref` is the finest clause true of that input and the run
reports whether the trace cited it. A block attributed to the wrong clause
still stops the call and still misleads the operator reading the log.
